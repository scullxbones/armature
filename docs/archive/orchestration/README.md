# Archive: Managed Execution (Historical)

These documents describe the `arm orchestrate` and `arm worker run` managed-execution
subsystem that was removed in the ORCRMV story. They are preserved here for historical
reference only.

**These designs are no longer active.** The `internal/orchestrate` and
`internal/workerruntime` packages have been deleted. The `arm orchestrate` and
`arm worker run` commands no longer exist.

For current orchestration guidance, see:
- `docs/commands.md` — current CLI reference
- `docs/getting-started.md` — current workflow
- `.claude/skills/armature-coordinator/SKILL.md` — coordinator workflow
- `.claude/skills/armature-worker/SKILL.md` — worker workflow
